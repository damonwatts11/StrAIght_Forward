# StrAIght Forward

AI-tutored pre-university mathematics learning platform.

An intensive pre-university mathematics course (15 sessions) paired with a
**Socratic AI tutor** that guides the student through successive questions
**without handing over the solution**.

## Goals
- Deliver a structured 15-session pre-university math curriculum.
- Provide a Socratic tutor that prompts reasoning instead of giving answers.
